# ArthroLive Image Manifest

All 26 supplied originals were inspected, classified by their actual subject, renamed
with descriptive SEO-friendly filenames and placed in exactly one section each.

- **Originals:** `source-images/` (untouched PNG/JPG masters, renamed only)
- **Web derivatives:** `public/images/*.webp`, generated by `npm run images`
  (widths 400 / 700 / 1000 / 1400, quality 74, served via `srcset` + `sizes`)
- **No image is used in more than one section.** No stock photography, no placeholders.

## Pricing cards

No distinct bundle photographs were supplied for the three packages, so rather than
repeating one photograph three times the pricing cards use drawn quantity illustrations
(`src/components/PackVisual.astro`) that show the accurate number of tea pouches and
balm jars in each package.

## Delivery notes

- Every image is served as WebP with explicit `width`/`height`, so nothing shifts as it
  loads (CLS).
- The hero image is `fetchpriority="high"`, eagerly decoded and preloaded in `<head>`.
- Every other image is `loading="lazy"` and `decoding="async"`.
- All alt text describes the actual subject of the photograph.
- To regenerate every derivative after replacing a master: `npm run images`.
